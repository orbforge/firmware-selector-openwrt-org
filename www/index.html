sensorbox

Customize your sensorbox

Pick a supported device, configure and customize it, and get a ready-to-flash sensorbox image. See the project goals for what sensorbox is and isn't.

Orb Deployment Token from https://cloud.orb.net/orchestration

Used for remote PCAPs and emergency SSH access. sensorbox devices are designed to be reflashed, not reconfigured

2-letter country code (US, GB, DE, JP, AU, etc.)

System telemetry (optional)

Push CPU, memory, disk, and temperature metrics from this probe to a self-hosted orb-local-analytics stack. Credentials are baked into the image and cannot be changed without reflashing.

Wi-Fi link stats are redundant with Orb's own wifi_link dataset; leave off unless running without Orb.

Tailscale (optional)

Join the device to your tailnet on first boot. Hostname is set to the auto-generated Orb-NNNN and Tailscale SSH is enabled (so you can SSH via tailnet identity without exposing dropbear publicly). Generate an auth key at login.tailscale.com/admin/settings/keys.

Burned into the image. Reflash to change.

Docker (optional)

Install the Docker daemon + Compose plugin on first boot, and enable dockerd at startup. SSH in afterward to run docker compose up against whatever workloads you want. Adds ~50 MB to the image.

Adds a /usr/bin/scandump wrapper around ghcr.io/dboze/scandump. Lets Wi-Fi Explorer Pro's remote-sensor flow (ssh sensor scandump wlan0 -) work transparently. Image is pre-pulled on first boot when network is available. Selecting this also installs Docker.

Advanced: additional uci-defaults

Optional. Appended after the recipe's device-specific uci-defaults and the sensorbox common pre-amble. Runs once on first boot. Remember that networking is not yet up when uci-defaults runs.
